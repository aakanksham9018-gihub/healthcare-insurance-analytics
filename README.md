# Healthcare Insurance Analytics Dashboard
## Project Overview
This project analyzes healthcare insurance enrollment, eligibility, and claims data to identify trends, optimize claims processing, and generate business insights.

## Tools Used
- Oracle SQL
- Power BI
- Microsoft Excel

## Objectives
- Analyze member enrollment and eligibility data
- Track claims approval, rejection, and pending trends
- Identify high-cost healthcare providers
- Monitor healthcare utilization patterns
- Build interactive dashboards for business reporting

## Dataset
The project contains:
- Member Enrollment Data
- Eligibility Data
- Claims Data
- <a href="https://github.com/aakanksham9018-gihub/healthcare-insurance-analytics/blob/main/Dataset%20-%20Excel.xlsx">Dataset</a>

## SQL Analysis
Key analyses performed:
- Member enrollment analysis  
- Active vs inactive member analysis  
- Claims status analysis  
- Hospital-wise claim analysis  
- Approval rate calculation  
- Member-claims relationship analysis  
- Eligibility validation  
- High-value claim identification

### View SQL Scripts
- <a href="https://github.com/aakanksham9018-gihub/healthcare-insurance-analytics/blob/main/healthcare_queries.sql">View SQL queries</a>

## Dashboard Features
### KPIs
- Total Members
- Active Members
- Inactive Members
- Total Claims
- Approved Claim Amount
- Total Claim Amount

### Visualizations
- Claims Status Distribution
- Plan Type Distribution
- Gender Distribution
- Age Group Distribution
- Monthly Claims Trend
- Hospital-wise Claim Amount

## Key Insights
- Active members represent approximately 85% of total enrollment.
- Gold Plan has the highest member enrollment.
- Apollo Hospital recorded the highest claim amount.
- Approved claims account for the majority of submitted claims.
